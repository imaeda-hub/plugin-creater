# 仕様書の書き方

## 置き場所とファイルの分け方

- 仕様書は `docs/specs/` に置く。
- 仕様書はすべてクリエイターの仕様書である。
- クリエイターの機能ごとにファイルを分ける。クリエイターが出力する生成プラグインの要件も、機能の1つとして扱う。

## 要件の番号

- 要件には、すべての仕様書を通した通し番号を付ける（例：`REQ-001`）。

## 要件の書き方

1つの要件は、次の3つで書く。

| 項目 | 内容 |
| --- | --- |
| 要件 | 満たすべきこと |
| 根拠 | 要件のもとになった憲章の条項 |
| 受け入れ基準 | 要件を満たしたと判断できる条件 |

例：

```markdown
## REQ-001 準拠仕様

- 要件：生成プラグインは、Agent Plugins 1.0.0 と GitHub Copilot CLI の公式プラグイン仕様に従う。
- 根拠：憲章 第5条
- 受け入れ基準：
  - Agent Plugins 1.0.0 の仕様に適合している。
  - GitHub Copilot CLI でインストールして使える。
```
