## 決めたこと

- 憲章の条番号は、クリエイター憲章（0.25.0）と同じにする。第3章（第11〜18条）と第4条は載せないので欠番になる。理由：根拠の参照、他の部品（統括の定義など）が条番号で引くときに、対応表なしで合う。憲章の冒頭に欠番の理由を1行書く。
- 条文（第5〜10条、第19〜24条）は、写すだけで言葉の置き換えは要らなかった（本文に「クリエイター」「生成プラグイン」の語がない）。置き換えは総則（目的、構成、用語）だけ。
- 仕様書の根拠は、生成プラグインの憲章にある条だけを指す。クリエイター憲章の第15条・第17条（クリエイターの章）は、生成プラグインの憲章にないので外した。クリエイターのナレッジ（.claude/memory）への参照も外した（生成プラグインのリポジトリにない）。
- 追跡の表：1行に1つの確かめ方。同じ要件の番号の行が複数あってよい（A3 へ）。ファイルの列は、ファイルかフォルダ（末尾 /）をバッククォートで囲んで、読点で区切る。`{{plugin_name}}` は組み立てで置き換わった後のパスになる。テストの列は、パス（グロブ可）をバッククォートで囲む。人が確かめる行は「—」。
- README のインストールは、手元のフォルダのマーケットプレイス経由（公式 docs の plugin reference に `copilot plugin marketplace add /PATH/TO/my-marketplace`、plugins-finding-installing に `copilot plugin install PLUGIN-NAME@MARKETPLACE-NAME`）。
