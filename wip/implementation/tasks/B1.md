## 決めたこと

（実装しながら足す。方針は下）

- 設計の骨組み：`adapter.mjs` は `startAdapter({ joinSession })` を出す。プラグインの根は adapter.mjs 自身の `import.meta.url` の3つ上（`extensions/<名前>/` の3つ上）。`extension.mjs` は `joinSession` を読み込んで渡すだけ。SDK の import は extension.mjs にだけ置く。
- `joinSession` の時点でツールを渡す必要があるが、core は session ができた後（port、sessionId、cwd が要る）にしか作れない。そのため、ツールの定義は `core.toolDefinitions` と同じ `buildToolDefinitions(pluginName)`（core/tools.mjs）で作り、ハンドラーは core が出来るまで待つ。フックと許可の受け口は、core が出来る前は何もしない（フックは通す、受け口は no-result）。
- 試験は、extension フォルダを一時のプラグインの形（plugin.json、task.json、agents/ つき）に写し、写した adapter.mjs を読み込んで動かす。プラグインの根を求める処理が本番と同じになり、本体に試験のための引数を足さずに済む。
