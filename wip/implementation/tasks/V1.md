## 見つけた不具合（実装を直す必要があるもの）

- **【重大】生成プラグインの作業エージェントと検証エージェントは、統括エージェントが持つツールしか使えない。** Copilot CLI 1.0.102 は、サブエージェントのツールを、親（統括エージェント）が持つツールとの共通部分にする（更新履歴 1.0.67「Subagent sessions keep parent tool restrictions」、1.0.68「Custom agents keep their tool filters in nested subagents」）。ひな形の orchestrator.agent.md の tools は `agent, read, search, plan, review, issue, finish, show` で、`verdict`・`edit`・`execute` を持たない。その結果、実機の偽物のモデルでは、検証エージェントのツールは `view, grep, glob` だけで `<名前>_verdict` が使えず（「Tool 'weekly-report_verdict' does not exist」）、作業エージェントは `edit`（create/edit）・`execute`（bash）を使えない。統括の tools に `<名前>_verdict`・`edit`・`execute` を足した写しでは、検証が `<名前>_verdict` を使え、作業が bash を使え、実行が `all_passed` で終わった。直し方の案は報告の 5 節。
