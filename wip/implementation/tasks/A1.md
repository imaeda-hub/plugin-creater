## 決めたこと

- 窓口の呼び出しの待ち時間の上限は 10 秒、止める処理の打ち切りは押してから 8 秒（constants.mjs の LIMITS）。
- 記録のファイルは同期の fs で書く（書く順番が確実で、試験で時計を進めるだけで済む）。
- 画面（A2）の作りに合わせた点：`core.start`・`core.stop`・`core.fileIssue` は、断るときに Error を投げる（message は平易な日本語）。`getFile` は `{ path, name, image }`。作業ごとの表示の値は A2 の render.js の形（kv は `{見出し:値}`、table は `{columns, rows}`、progress は 0〜100 の数か `{value,max,label}`、image・file は `{fileId, name}`）。
- 準備中は `state.run === null`（`run.status` の `preparing` は使わない）。開始に失敗して準備中に戻ったときは、状態の全体に `startError: { message, unknownLaunch }` を足す。
- `canFile.reason` は画面がそのまま出せる平易な日本語の文。記号は `canFile.code`（no_repository・not_github・no_gh・not_logged_in）に足した。`canFile.repo`（OWNER/REPO）も足した。`steps` は平易な日本語の文の配列。
- `endReason.detail` の記号：`cut_off`・`credit_limit`・`chat_interrupted`・`orchestrator_failed`・`orchestrator_ended`・`retry_limit`（A2 の ABORT_DETAILS と同じ）。`endReason.message`（失敗の内容など）を足した。
- `previous` に `runId` を足した。

## 要確認
