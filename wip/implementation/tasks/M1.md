## 決めたこと

- ひな形の場所の示し方は、「Base directory for this skill」からの相対位置（`../../template/`）にした。理由：今の手順では、メインのエージェントが場所を作業エージェントと task.schema.json の指定に渡すだけで、スクリプト（scaffold.py）は自分で場所を求める。場所を返す仕組み（スクリプトやエクステンションの新しいコマンド）を足すと、設計書にないものが増える（KISS）。`generate.md` が既に `<スキルのフォルダ>/../test-plugin/scripts/check_tools.py` の形を使っているので、同じ書き方にそろえた。`..` を畳んだ絶対パスで渡すよう添えた。
- SKILL.md の「自分では読まない」は残した。場所を generate.md で作業エージェントに渡すので、メインのエージェントは場所を知っており、読めば約80ファイルが会話に入る。Related files の問題（ファイル名が毎回届く）は移して解消するが、読むとコンテキストが埋まる問題は残るため。
- tests/dev-eval/convert.py の `assets/` と `scripts/` を置き換えない規則は残した（一般の規則として有効で、見本のスキル `skills/demo/assets/` の試験もそのまま通る）。直下の `template/` は `copy_plugin_files` がそのまま写し（除外の一覧に入れていない）、`convert_skills` は `skills/` の下だけを扱うので置き換えない。この規則は、見本に直下の `template/com.github.copilot/agents/t.agent.md` を足した試験（`test_4_the_template_at_the_root_is_copied_and_not_replaced`）で守る。
- test_convert.py の `assert_no_copilot_names_left` にあった `skills/make-plugin/assets` を飛ばす分岐は、その場所がなくなったので消した（直下の `template/` は、その関数が見る `agents`・`skills` の下ではない）。
