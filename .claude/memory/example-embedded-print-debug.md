# 実例：組み込み機器のプリントデバッグ

## 繰り返すフェーズ

コード修正 → クロスコンパイル → デプロイ（モジュールの転送）→ デバッグ → ログ取得 → ログ検証

## そのままの AI でできること・できないこと

| フェーズ | そのままの GitHub Copilot CLI | ハーネスエンジニアリング後 |
| --- | --- | --- |
| コード修正 | できる | — |
| クロスコンパイル | できない（特殊なビルド手順を踏む必要があるため） | スキルにすれば、AI が自律的にできる |
| デプロイ | できない（組み込み機器にモジュールを転送できないため） | スキルと、その中のスクリプトなどで、AI が自律的にできる |
| デバッグ・ログ取得 | できない（コンソールからログを取れないため） | スキルと、その中のスクリプトなどで、AI が自律的にできる |
| ログ検証 | できる | — |

## 結果

- コード修正、クロスコンパイル、デプロイ、デバッグ、ログ検証をすべて AI が自律的にできるようになれば、プリントデバッグがヒューマン・イン・ザ・ループからヒューマン・オン・ザ・ループに変わり、効率が飛躍的に上がる。
