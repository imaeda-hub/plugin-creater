# AI エンジニアリングの5分類

現在、AI エンジニアリングでは次の5つが提唱されている。表は提唱された順で、グラフエンジニアリングが最も新しい。

| 名称 | 内容 |
| --- | --- |
| プロンプトエンジニアリング | AI から質の高いアウトプットを得るために、最適なプロンプトを入力する |
| コンテキストエンジニアリング | AI に適切な情報を渡し、AI のコンテキストウィンドウを最適化する |
| ハーネスエンジニアリング | LLM を包むハーネスを構築する |
| ループエンジニアリング | AI が自律的にループ処理できるハーネスを構築する |
| グラフエンジニアリング | マルチエージェントにおけるエージェントの構成などを設計する |

## コンテキストエンジニアリング

- LLM には、LLM の種類に応じて決まったサイズの領域（コンテキストウィンドウ）が一つ用意される。
- この領域を、達成したい目的に沿った情報だけにし、目的と関係のない情報はむしろ入れないように最適化する。

## ハーネスエンジニアリング

- AI は、コアとなる LLM と、それを囲むハーネスで構成される。LLM を包むものはすべてハーネスと言えるほど、広い定義である。
- GitHub Copilot や Claude Code、特に GitHub Copilot CLI では、サンドボックスなどの環境面に加え、スキル、インストラクション、カスタムエージェント、MCP、フックなどでハーネスを構成できる。

## ループエンジニアリングとグラフエンジニアリング

- どちらもハーネスエンジニアリングに含まれる。
- ループエンジニアリングは、AI が自律的にループ処理できるハーネスの構築に特化したもの。
- グラフエンジニアリングは、マルチエージェントにおけるエージェントの構成などの設計に特化したもの。
