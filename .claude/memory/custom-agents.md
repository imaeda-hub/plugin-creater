# カスタムエージェント（GitHub Copilot CLI）

## 役割

- 主にマルチエージェント構成を作るために使う。
- マルチエージェント構成の中の1つのエージェントを定義する。
- 定義したエージェントを組み合わせて、マルチエージェント構成を作る。

## フロントマター

- ヘッダー部にフロントマターを書く。
- 必須フィールドは `name` と `description`。
  - 要確認：公式ドキュメントで未確認。コミュニティの資料には、`description` だけが必須で `name` は任意とするものもある。
- オプションで次のような項目を設定できる。
  - 使用するモデル（特に有効）
  - 権限（書き込み権限、読み取り権限など）（要確認：公式ドキュメントで未確認）
  - 呼び出せるサブエージェント（要確認：公式ドキュメントで未確認）
  - 使えるツール
