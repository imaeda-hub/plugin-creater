# ハーネスの調達

ハーネスは、すべてを自作するわけではない。

1. **Copilot CLI の標準機能**：ビルトインされた機能を使う。例：スラッシュコマンドの `/plan`、`/review`、`/fleet` など。
2. **OSS のプラグイン**：多数のプラグインが公開されている。有名なのは公開リポジトリの Awesome Copilot。
3. **自作**：それでも見つからない場合や、自分たちの製品に固有のハーネスを作る場合に自作する。

## ユーザーの既存資産

- ユーザーは、これから作るプラグインに組み込む資産をすでに持っていることがある。
- そのため、一から作る前に、対話を通じて既存の資産がないかを確認して引き出し、あるものは流用する（憲章 第11条）。
