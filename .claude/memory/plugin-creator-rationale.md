# プラグインを作るプラグイン（ハーネスの作り方）

今回のプロジェクトの根幹となる考え。

- ハーネスを作ってプラグインで配布する。つまり、配布するプラグインをこれからどんどん作っていく必要がある。
- しかし、毎回一から作るのは非効率である。
- プラグインには共通する部分がある。共通する考え方、共通するアーキテクチャ、共通する大事なことがある。
- だからこそ、プラグインを作るプラグインが大事になる。
- レベルの高いプラグインを再現性高く作れるプラグインを作れれば、これからのハーネスエンジニアリングの質と開発スピードが格段に上がる。これがとても重要である。

## クリエイターの中心は、人間からナレッジを引き出すこと

- ハーネスづくりで大事なのは、人間からナレッジを引き出すことである（[ハーネスエンジニアリングの目的と人間の役割](harness-purpose.md)）。
- クリエイターは、プラグインを作るプラグイン、つまりハーネスを作るプラグインである。
- だから、人間からナレッジを引き出す部分が、クリエイターの中心であり、一番大事な部分である。
- これからクリエイターを作っていくうえで、この部分を大幅に強化していく。
