# 自己改善

- Agent Plugin はいろいろな人に使われるが、常に自己改善を心がける必要がある。

## 進め方

1. 実行中に、適切にログを残す。
2. 実行後に、ログを振り返って問題点を洗い出す。観点の例：
   - 何かの実行に失敗していないか
   - AI の振る舞いが詰まったり止まったりしていないか
   - データがきれいに流れているか
3. 毎回ログからフィードバックし、自分自身への改善提案をする。これによって自己改善を重ねていく。

## Issue の発行

- プラグインは GitHub で管理されることが多いため、プラグイン自身が最後に自分のリポジトリへ Issue を発行することが推奨される。
