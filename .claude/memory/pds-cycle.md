# AI の思考サイクル（PDS）

- AI の思考サイクルも人間と同じく、基本的には PDS（Plan・Do・Study）が大事である。
  - Plan：必ず最初に計画を立てる。
  - Do：計画を実行する。
  - Study：実行した後は、必ず評価や学習を行い、次の計画につなげる。
- ただ実行を繰り返すのではなく、必ず計画・実行・評価のサイクルを回す。これは人間にとっても AI にとっても大事である。
- プラグインはハーネスを提供するものだが、そのハーネスでできたヒューマン・オン・ザ・ループでは、この思考サイクルが大事になる。

## 例：printf デバッグ

- Plan：どこに、どのようなコード修正をするか、printf をどこに差し込むかを計画する。
- Do：計画したコード修正を実施する。
- Study：最後にログを見て評価し、次の計画につなげる。
- 闇雲にソースコードの修正や printf の追加を繰り返していては、問題解決に至らない。
