# 段階「実物を受け取る」

目的：前回の1回で受け取ったファイルと作ったファイル、いつも使っているファイルの場所を受け取る。これらは、決まりの候補の元、流用する資産の候補、試験の課題の入力になる。

## 問い

- 1つの問い（聞き出す問い）で、まとめて書いてもらう。「ない」とも答えられるようにする。
- 問いの例：「実際のファイルがあると、AI が書き方や決まりを取り違えにくくなり、できあがるプラグインを試しに動かすときの入力にも使えます。最近この作業をしたときに受け取ったファイルと作ったファイル、いつも使っているファイル（テンプレート、手順書、スクリプトなど）は、どこにありますか？ファイルの場所（パス）か @ で書いてください。ない場合は「ない」と書いてください。」
- 括弧の中の並びは、どのファイルを指すかを示す言葉なので、答えの例とみなさずに残す。
- 作り直しでは、元のプラグインのフォルダは受け取り済みなので、前回の1回のファイルといつも使うファイルだけを聞く。

## 受け取り方

- 場所（パスか `@`）で受け取る。中身の貼り付けは頼まない。例外は、PDF をそのまま読めず、テキストにしてもらうとき（`references/read.md`）である。
- 答えに `<pasted_content file="…" />` が入っていたら、そのファイルも示されたファイルとして記録する。
- 示されたファイルの場所を、`plugin-creator_record` で流用する資産の候補として記録する。
- 「ない」と答えたら、記録するものはない。

## 次へ

- ファイルが1つ以上あれば（作り直しなら必ず）、段階を「読む」に進める。
- ファイルがなければ、段階「読む」と「決まりの確かめ」を飛ばし、段階を「前回の1回」に進める。試験の課題の入力は、生成前の確認で仮のファイルにする。
