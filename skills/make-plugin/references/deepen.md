# あいまいな答えを聞き直す型

段階「前回の1回」から「生成前の確認」まで、答えを受けるたびに使う。

## 聞き直す合図

答えに次のどれかがあれば、聞き直す。

1. 基準のない形容詞・副詞（「見やすく」「ちゃんと」「適切に」「早めに」）
2. 「普通」「いつもどおり」「適当に」
3. 一般論・仮定（「普通は〜」「〜だと思う」「場合による」）
4. 範囲のぼかし（「など」「いろいろ」）
5. 本人だけの言葉（略語、社内用語、固有名）
6. 矛盾（前の答えや、示されたファイルと食い違う）
7. 判定できない合否（「良ければ合格」）

## 合図ごとの型

| 合図 | 型 | 問いの例 |
| --- | --- | --- |
| 基準のない形容詞 | 見分け方を聞く。数、有無、見本に落ちたら止める | 「見やすいかどうかは、どこを見れば分かりますか？」 |
| 普通・いつもどおり | 実際の1回を聞くか、初めての人がつまずく所を聞く | 「最近の1回では、どう書きましたか？」 |
| 一般論・仮定 | 実際にあった1件に戻す。何を見て、何をしたかを聞く | 「最後にそれをしたときは、何を見て決めましたか？」 |
| 範囲のぼかし | ないと言われるまで、ほかを聞く | 「ほかにはありますか？」 |
| 本人だけの言葉 | 意味を聞く | 「〇〇とは、何のことですか？」 |
| 矛盾 | 両方を並べて聞く | 「先ほどは A、ファイルでは B でした。どちらですか？」 |
| 判定できない合否 | 合格の例と、やり直しになった例を、1つずつ別の問いで聞く | 「合格だった例を1つ教えてください」の後に「やり直しになった例を1つ教えてください」 |
| 言い切りの決まり | 例外を聞く | 「それに当てはまらなかったときはありましたか？」 |

- 表の問いの例にも、なぜ聞くかの1文を前に置く（本文の「問いの形」）。
- 1つの問いで聞く点は1つにする。2つのことを聞くと、答えを読み分けにくくなる。
- 「なぜ」は目的を聞くときだけ使う。自分の行動の理由を聞くと、後から作った説明になりやすい。
- 推し量ったことを示すときは、「こう理解しました。違うところと足りないところを教えてください」と聞く。

## 聞き直しをやめるとき

- 記録する前の点検（本文の「記録のしかた」）で、作業を知らない AI がその1文だけで作業や判定ができる細かさになったら、それ以上は聞き直さない。
- 同じ点への聞き直しは2回までにする。問いの意味が伝わらなかったときの言い直しは、回数に数えない。
- 2回聞いてもあいまいなら、ユーザーの言葉のまま記録し、その項目を保留にして先へ進む。保留は、生成前の確認で示す。
- 問いの総数には上限を置かない。項目をすべて聞くためである。

## 「分からない」などの答え

| ユーザーの答え | 扱い |
| --- | --- |
| 問いの意味が分からない | なぜ聞くかと、どの細かさの答えがほしいかを足して、1回言い直す。聞き直しの回数に数えない |
| 決まっていない | その点は聞き直さない。項目全体に決まりがなければ、項目を「決まりなし」にする |
| 知らない・思い出せない | 項目を保留にし、だれが知っているか、どの資料にあるかを記録する |
| おまかせ | 理由つきの案を1つ示し、出どころを「AI の判断（ユーザーが任せた）」として記録する |
