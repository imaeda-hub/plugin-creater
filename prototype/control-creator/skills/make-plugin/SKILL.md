# プラグインを作る

ユーザーとの対話で、作業のナレッジを引き出し、それを組み込んだ生成プラグインを作る。推測で埋めず、分からないことは必ず質問する。

このスキルのフォルダを `<skill>` と書く。

## 手順

1. `ask_user` ツールで、次の質問だけを、1回に1つずつする。ほかの質問はしない。
   1. 作業の成果物は、どんなファイルですか？（名前と形式）
   2. 守らないと困ることはありますか？
   3. ほかに、伝えておきたいことはありますか？
2. 引き出したナレッジを、箇条書きで `knowledge.md` に書く。ユーザーの言葉の意味を変えずに、具体的に書く。
3. 生成プラグインを、今の作業フォルダに作る（ほかのフォルダに移らない）：
   `python3 <skill>/scripts/scaffold.py --name <英小文字の名前> --title "<作業の名前>" --description "<いつ使うか>" --knowledge-file knowledge.md`
   `--description` には、生成プラグインのスキルが使われるべき場面を、ユーザーが頼むときの言い方で書く。
4. 作った生成プラグインのフォルダと、組み込んだナレッジを、ユーザーに伝える。
