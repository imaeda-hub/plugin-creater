# プラグインを作る（対照）

大まかな質問を3つだけして、生成プラグインを作る。開発の試験の対照なので、ほかのことは聞かない。推測で足さない。

このスキルのフォルダを `<skill>` と書く。

## 手順

1. 次の3つの質問を、文章で、1回に1つずつ聞く。1つ聞いたら、その手番を終えて、ユーザーの答えを待つ。ほかの質問はしない。
   1. 作業の成果物は、どんなファイルですか？（名前と種類）
   2. 守らないと困ることはありますか？
   3. ほかに、伝えておきたいことはありますか？
2. 答えを、ユーザーの言葉の意味を変えずに、箇条書きで作業フォルダの直下の `knowledge.md` に書く。1行目に1つ目の答え、2行目に2つ目の答え、3行目に3つ目の答えを書く。答えがなかった質問の行は書かない。
3. 次のコマンドで、生成プラグインを今の作業フォルダに作る。
   `python3 <skill>/scripts/control_build.py --name <英小文字とハイフンの名前> --title "<作業の名前>" --description "<いつ使うか>" --knowledge-file knowledge.md`
   `--description` には、生成プラグインが使われるべき場面を、ユーザーが頼むときの言い方で書く。
4. 作った生成プラグインのフォルダと、組み込んだ内容を、ユーザーに伝える。
